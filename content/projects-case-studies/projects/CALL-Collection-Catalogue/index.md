**LDaCA is working with the Batchelor CALL Collection to create a sustainable, archivable version of its language data and metadata, supporting its long-term care, interoperability and appropriate access.**

The project will transform data and metadata from the existing CALL Collection database into archival formats designed for longevity and reuse. This includes implementing the RO-Crate metadata standard to package collection materials together with structured information describing them, creating data that is both self-describing and interoperable with other systems and software.

LDaCA will develop tools to automate this transformation process while retaining the collection’s existing access protocols. A simple website will provide controlled access to the archival-format collection, initially serving as an internal tool for viewing and working with the preserved data. This infrastructure could also provide the foundation for a future replacement of the existing CALL Collection website, depending on Batchelor’s needs.

The project is guided by FAIR and CARE principles, balancing the discoverability and accessibility of language materials with appropriate permissions, Indigenous Data Governance, community authority and responsibility throughout the data lifecycle.
